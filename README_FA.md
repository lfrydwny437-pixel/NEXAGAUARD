# NEXAGUARD PHP V3

نسخه تجاری‌تر ربات مدیریت گروه روبیکا با PHP و Webhook.

## امکانات

- پنل مالک جداگانه
- پنل مشتری جداگانه
- لایسنس واقعی با SHA-256 و انقضا
- پلن‌های ماهانه، دوماهه، سه‌ماهه، شش‌ماهه، سالانه، پنج‌ساله و دائمی
- اتصال لایسنس به حساب مشتری
- پشتیبانی تیکتی
- سفارش تبلیغ و قیمت‌گذاری از پنل مالک
- تأیید/رد تبلیغ
- هسته Webhook
- SQLite
- ضدلینک، ضداسپم، ضدفحش و اخطار
- بیش از ۲۲۰ دستور محلی سرگرمی/اطلاعات/مدیریت
- پاسخ‌های محلی بدون API هوش مصنوعی

## تبلیغات

فایل `cron/ads.php` برای اجرای دوره‌ای تبلیغ است. برای انتشار خودکار، باید Cron Job هاست آن را مثلاً هر ۲۴ ساعت اجرا کند. تبلیغ بدون اجازه مدیر گروه نباید به گروهی ارسال شود؛ جدول `ad_groups` برای تعیین گروه‌های مجاز است.

## نکته مهم درباره پرداخت

در این نسخه سفارش و تأیید تبلیغ و لایسنس وجود دارد، اما درگاه پرداخت بانکی به‌صورت پیش‌فرض اضافه نشده؛ اتصال درگاه به یک سرویس پرداخت ایرانی نیاز به اطلاعات و قرارداد همان درگاه دارد. می‌توان بعداً callback آن را به همین سیستم وصل کرد.

## نکته مهم درباره مدیریت ادمین/بن

API رسمی قابل اتکا برای تمام عملیات بن/آن‌بن/حذف ادمین در این پروژه فرض نشده است. بنابراین سیستم داخلی ادمین و سطح دسترسی ساخته شده، اما عملیات حساس روبیکا فقط وقتی باید فعال شود که متد رسمی آن در API ربات تأیید شده باشد؛ ربات نباید پاسخ جعلی بدهد که کار انجام شده است.

## AI محلی

دستورات و پاسخ‌های پایه کاملاً محلی هستند و API خارجی AI لازم ندارند. برای LLM واقعی، باید مدل روی خود سرور اجرا شود و سرور باید RAM/CPU کافی داشته باشد.

## راه‌اندازی

1. فایل‌ها را روی هاست PHP قرار بده.
2. PHP 8.1+، SQLite و cURL فعال باشد.
3. Document Root را روی `public` قرار بده.
4. متغیرهای محیطی `.env.example` را در تنظیمات هاست وارد کن.
5. `WEBHOOK_URL` را روی آدرس HTTPS قرار بده.
6. یک بار `/setup` را باز کن.
7. برای کار ۲۴ ساعته از هاست/سرور دائمی استفاده کن؛ گوشی تو لازم نیست آنلاین باشد.

## امنیت

توکن روبیکا را داخل GitHub یا فایل عمومی قرار نده. آن را فقط در Environment/Secrets سرور بگذار.


## استقرار روی GitHub + Render
این نسخه برای استقرار Web Service با Docker آماده شده است. فایل `Dockerfile` وب‌سرور PHP را روی پورت محیط `PORT` اجرا می‌کند و `render.yaml` تنظیمات سرویس را مشخص می‌کند.

### متغیرهای لازم در Render
- `RUBIKA_BOT_TOKEN`
- `OWNER_ID`
- `ADMIN_PANEL_KEY`
- `WEBHOOK_URL`

بعد از Deploy، مقدار `WEBHOOK_URL` را با آدرس HTTPS سرویس خودت تنظیم کن و سپس مسیر `/setup` را یک‌بار باز کن تا Webhook و فهرست ۶ دستور عمومی ثبت شوند.

### منوی عمومی ربات
فقط این ۶ دستور ثبت می‌شوند: `start`, `help`, `commands`, `panel`, `settings`, `status`. امکانات دیگر از پنل مدیریت استفاده می‌کنند.


### دکمه خرید مستقیم
برای نمایش دکمه «🛒 خرید لایسنس»، متغیر `SELLER_RUBIKA_USERNAME` را با آیدی روبیکای فروشنده، بدون `@`، تنظیم کنید؛ مثلاً `AR_1199`. دکمه، صفحه/چت همان آیدی را در روبیکا باز می‌کند و کاربر می‌تواند خودش پیام خرید را ارسال کند.
